# INDmoney US holdings integration

Goal: Import the owner’s INDmoney US stock holdings into Sumora net worth using the official read-only MCP server.

Design: Native ASWebAuthenticationSession → backend OAuth 2.1 PKCE + verifier-bound claim. Dynamically register a confidential client with the fixed production callback. Encrypt client credentials, access and refresh tokens in D1. Serialize refresh and sync to preserve rotated tokens. Read actual MCP tool schemas before mapping positions; request only US holdings, preserve fractional quantities and USD prices, and convert to INR using a dated FX observation. Failed requests retain the last snapshot; expired/revoked authorization prompts reconnect. No AI is required and no existing Indian holdings are imported again.

- [x] MCP transport: bounded JSON/SSE, session initialization, tools/list and tools/call; test errors, token refresh/rotation and session loss.
- [x] Live consent: deploy auth flow and connect the user; inspect real US holdings schema and token refresh behavior.
- [x] Portfolio: map verified schema, USD/INR conversion, cached positions, net-worth composition, scheduled/manual sync; test fractional quantities, duplicate prevention and retained data on failure.
- [x] iOS: connect/sync/disconnect/status, US holdings and FX provenance; simulator tests.

Progress: OAuth consent and authorized tool discovery succeeded. The US_STOCK response provides authoritative INR and USD values, so the importer uses reported INR amounts directly and labels its derived USD unit price / implied conversion as snapshot observations, not timestamped market quotes. Validated mapping, owner-scoped retained snapshots, generation-safe writes, manual sync, US allocation/net-worth composition, and a dedicated 15-minute background schedule are implemented. Daily US returns are deliberately unavailable until a compatible midnight reference exists; INDmoney's trading-session return is not substituted for Sumora's daily baseline. Local validation: 75 backend tests, typecheck and 32 native tests pass; iPhone build succeeds. Production migration and deployment succeeded (the initial Cloudflare API timeout was resolved by retry). A live authenticated backend import returned six US holdings; USD quotes and INR allocation reconcile with the portfolio response. That production response also decoded using the app’s actual Swift models. The updated app is installed on the iPhone. Verification sessions were removed immediately. Scheduled triggers are confirmed deployed; future unattended runs and long-term provider session lifetime remain operational observations, not claims from this test.
