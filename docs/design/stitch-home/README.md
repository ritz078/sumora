Project: Ledger Wealth Dashboard (`7332412299640222202`). Screen: Home (`7042941f5fdf4c0192a1192644a8547d`). Retrieved 10 October 2026.

`reference.html` is the downloaded Stitch code. `reference.png` is its full-resolution 780 × 3326 screenshot (390-point layout at 2×).

The native implementation uses the bundled Inter font, 16-point page margins and card gaps, 20-point card padding, and 16-point card corners. Daily performance uses a two-column grid. The header includes a direct demo-data toggle and a compact Zerodha sync status panel; Connected Accounts is omitted from the homepage. Settings and connection management remain accessible through the profile avatar. The chart keeps its price labels inside the plot and dates in a separate footer.

Portfolio amounts, allocation rows, account states, and history come from actual app data. Missing daily baselines remain unavailable; history begins when snapshots were recorded. The system status bar and accessibility text scaling remain native.
